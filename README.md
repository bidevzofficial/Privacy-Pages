# BiSoftic Privacy Center

Public privacy policies and account-deletion pages for BiSoftic apps, served with GitHub Pages
(`https://bidevzofficial.github.io/Privacy-Pages/`).

| App | Privacy policy | Account deletion |
|---|---|---|
| Ludo Play (`com.bisoftic.ludoplay`) | `ludoplay/privacy.html` | `ludoplay/delete-account.html` |

Rules: each page must describe what the released app actually does (re-check after every SDK change),
keep the "Last updated" date current, and never remove a page an app still links to.
